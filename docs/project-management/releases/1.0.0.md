# Release 1.0.0

First release of the Beeswax theme, a customised Mercury with a bee, honey and wax look, skinned for HiveLog.

## Highlights
- HiveLog entity forms themed: vertical tabs (menu no longer clipped by `overflow:hidden`) and Tom Select on entity-form selects, matched to the text inputs' width.
- The HiveLog table filter form and its selects themed with Tom Select; fixes for the control going white on interaction.
- Bridge to the `--hivelog-*` tokens, replacing the copied `hivelog-page` styles.
- Danger-button hover shade.
