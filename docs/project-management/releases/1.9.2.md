# Release 1.9.2

Lighter HiveLog CSS, dark mode that survives a strict Content-Security-Policy, reduced motion honoured everywhere, and a more neutral, translatable footer.

## Highlights
- The HiveLog stylesheet is minified (about 21 KB smaller).
- The "match the device" dark-mode switch is a script file instead of inline script, so a strict Content-Security-Policy no longer leaves the page light.
- Visitors who ask for reduced motion get no transitions or animations from the theme.
- Notes for maintainers: Tom Select upgrade steps and why the few `!important` rules exist.
- The footer's app link is worded by a new setting, **Footer: app link label**; the credit line is one translatable string; the versions line can be switched off.
- Removed unused files, refreshed the README and `composer.json`, and slimmed `screenshot.png` (it still shows the Mercury demo).

## Upgrade notes
- A site that has a footer app link set now reads "Get the app". Set **Footer: app link label** under Appearance > Beeswax (for example "Get the Vinculum app") to keep the old wording.
- The credit line's screen-reader text for the sparkle is now "sparkles" rather than "AI".
