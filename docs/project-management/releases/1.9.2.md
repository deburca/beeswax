# Release 1.9.2

Lighter HiveLog CSS, dark mode that survives a strict Content-Security-Policy, and reduced motion honoured everywhere.

## Highlights
- The HiveLog stylesheet is minified (about 21 KB smaller).
- The "match the device" dark-mode switch is a script file instead of inline script, so a strict Content-Security-Policy no longer leaves the page light.
- Visitors who ask for reduced motion get no transitions or animations from the theme.
- Notes for maintainers: Tom Select upgrade steps and why the few `!important` rules exist.
