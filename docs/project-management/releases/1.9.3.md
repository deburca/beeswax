# Release 1.9.3

Accessibility fixes from the first full audit on a running HiveLog site.

## Highlights
- Small grey text, the warning and critical chips and the borders of form fields now meet WCAG contrast (4.5:1 for text, 3:1 for controls). **Input borders are visibly darker.**
- The filter selects are labelled for screen readers, the logo no longer repeats the site name, and status messages use the `status` and `alert` roles.
- The two large example images in the image and card components are smaller (about 170 KB saved).
- The main navigation has an accessible name ("Main navigation"); it was empty.
- Maintenance: the PHP coding standard now runs in CI, and the footer code has kernel tests.

## Upgrade notes
- The Vinculum app's `Palette.swift` needs the new `--bw-warning` (`#965a08`) and dark `--bw-critical` (`#e8756c`) to stay in step.
