# Release 1.8.0

Framed account pages and running text.

## Highlights
- Account pages framed as cards; edit and cancel account in a wider card; only a card's second button is quiet.
- Footer modelled on shh, with versions under the links on the line of the credit.
- Running-text styles for a page body (such as a privacy policy), with a serif title.
- Docs on keeping module user pages out of the admin theme.
